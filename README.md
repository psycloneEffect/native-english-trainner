# Native Biz-English Trainer

日本人がビジネスの場でつい使ってしまう英語を、ネイティブの言い方に置き換える教材を作るツールです。
場面とその表現を入れると、なぜ不自然に聞こえるのか、相手にどう受け取られるのか、
代わりに何と言えばいいのかを、1件のノート（Markdown）にまとめます。

**URL: https://native-english-trainner.ai-builds-lab.workers.dev/**

所内限定のツールです。IDとパスワードは、共有した人から受け取ってください。

---

## 使い方

### 1. ログインする

URLを開き、IDとパスワードを入れて「ログイン」を押します。一度ログインすると、
同じブラウザでは7日間そのまま使えます。終わったら画面右下の「ログアウト」で抜けられます。

### 2. 3つの欄を埋める

| 欄 | 入れるもの | 例 |
|---|---|---|
| どんなシチュエーションですか？ | **必須。** 誰に、どんな状況で言う場面か | 難関資格に苦労して合格した同僚から「I finally passed!」と報告された |
| つい言ってしまう表現 | **必須。** 自分が言ってしまいそうな英語 | Oh great. |
| ネイティブならこう言う | **任意。** 正解の言い方が分かっていれば入れる。**空欄なら、場面に合う言い方を探します** | Way to go! |

場面は具体的に書くほど、解説が的確になります。「誰に」「何があった後に」を入れるのがおすすめです。

欄の右端の ✕ で、その欄だけを消せます。

### 3. Ask を押す

辞書サイトを調べながら書くため、**30秒〜1分ほど**かかります。途中でやめたいときは「停止」を押します。

### 4. 結果を確かめて保存する

結果は「プレビュー」と「Markdown」のタブで切り替えて確認できます。

- **Markdownをダウンロード**: ノートを `.md` ファイルとして保存します
- **作り直す**: 同じ入力で生成し直します（実行回数を1回使います）
- **閉じる**: 結果を閉じます（入力はそのまま残ります）

保存するファイル名は `001_相手の成功を祝う表現.md` のように、番号と見出しが付きます。
番号は保存するたびに1つ進みます。番号を変えたいときは「ファイル番号」の欄に直接入れ、
最初からやり直すときは「001に戻す」を押してください。

番号はブラウザごとに覚えています。別のパソコンやブラウザでは 001 から始まります。

## できあがるノートの中身

| 見出し | 内容 |
|---|---|
| シチュエーション | 入力した場面 |
| ❌ 日本人がやりがちなNGフレーズ | つい言ってしまう表現と、似たもの |
| 💡 なぜNGなのか？ | 相手にどう聞こえてしまうのかの解説 |
| 🎭 この場面での印象の違い | NGの言い方とネイティブの言い方で、受け取られ方がどう変わるかの比較表 |
| ⭕️ ネイティブが使う自然なOKフレーズ | 同僚向け（Standard）と、上司・顧客向け（Formal）の言い方 |
| 📖 ソース・参考情報 | 確認に使った辞書と、そのリンク |

## 実行回数の上限

使いすぎを防ぐため、1日に実行できる回数に上限があります。
**Askボタンの左に「本日の残り N 回」**と出ていて、残りが少なくなると赤くなります。

- 上限は「この端末で1日○回」と「全員で合わせて1日○回」の2つです
- 毎日 **0時（日本時間）** に戻ります
- 「作り直す」も1回に数えます。生成に失敗した場合も数えます

上限に達すると、いつ戻るかが表示されます。正確な残りは、画面の表示を見てください。

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| IDまたはパスワードが違います | 入力を確認してください。前後に空白が入っていないかも確かめてください |
| ログインの有効期限が切れました | もう一度ログインしてください。入力した内容は残っています |
| シチュエーションと、つい言ってしまう表現を入力してください | 必須の2つの欄を埋めてください |
| 生成結果の形式が不正でした | もう一度 Ask を押してください。たいていは2回目で通ります |
| 本日の〜の実行回数の上限に達しました | 表示された時刻まで待ってください |
| 画面の版とサーバーの版が一致していません | `Ctrl + Shift + R`（Mac は `Cmd + Shift + R`）で再読み込みしてください |
| それ以外のエラー | 表示されたエラー文（`code:` の部分を含む）を、ツールの管理者に伝えてください |

## 使うときの注意

- **内容はAIが書いたものです。** 教材として使う前に、自分でも確かめてください。
  出典欄で裏付けが取れなかった項目には「（未検証）」と付きます
- **IDとパスワードは他の人に教えないでください。** 実行のたびに費用がかかるためです
- 入力した内容は、生成のために外部のAIサービス（Claude）に送られます。
  社外秘の情報や個人名は入れないでください
